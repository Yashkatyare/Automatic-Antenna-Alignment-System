ETE Major Project · RF & Embedded Systems

Automatic Antenna Alignment System for Optimized Wireless Communication

An ESP32 DevKit-based Wi-Fi alignment prototype: it reads RSSI from a connected access point, scans a platform from 0° to 180° in 15° steps with an MG996R positional servo, then returns to the strongest measured angle. The website animation is a simulation, not live hardware telemetry.

How the Automatic Antenna Alignment System Works

Illustrative simulation of the workflow: Wi-Fi source connection, RSSI scanning, servo alignment, and local status reporting. Displayed animation values are not hardware measurements.

Wi-Fi Link

RSSI Scan

ESP32
