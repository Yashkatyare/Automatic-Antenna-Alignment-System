Hardware Bill of Materials

Project Hardware Components

Current prototype hardware, the original signal-source concept, and external-antenna integration status.

ESP32 DevKit Receiver

The rotating receiver/controller reads Wi-Fi RSSI from the connected access point with the ESP32 Wi-Fi software interface, processes scan results, controls the servo, and updates the LCD.

  • Measurement WiFi.RSSI() (dBm)
  • Servo signal GPIO18
  • Button input GPIO19 / INPUT_PULLUP
  • Power USB or regulated supply

Wi-Fi Signal Sources

The currently tested configuration connects to the smartphone hotspot named realme12+5G. The original dual-source concept also included an ESP32-WROOM-32E Wi-Fi source; the two sources are alternatives, not simultaneous inputs in the current setup.

  • Current source Phone hotspot
  • Hotspot name realme12+5G
  • Original concept ESP32-WROOM-32E source
  • Connection One Wi-Fi access point

External Directional Antenna

Teleten wideband directional patch-panel antenna. This is intended for external integration and is not confirmed as connected to the working prototype.

  • Advertised gain 8 dBi
  • Advertised range 698–2700 MHz
  • 2.4 GHz Wi-Fi Within advertised range
  • Specification Seller-advertised; unverified
  • External RF option ESP32-WROOM-32U variant
  • Connector / adapter Small RF connector; matching pigtail required

The WROOM-32U is not a complete USB development board and needs compatible hardware. It is not interchangeable with the WROOM-32E antenna connection. Seller-listed typical use: indoor LTE service distribution; compact, lightweight, easy to install, low return loss, high gain, stable performance. No measured 8 dBi gain or Wi-Fi test is claimed.

MG996R Positional Servo

A positional servo rotates the antenna platform through commanded scan positions, then positions it at the selected best angle.

  • Signal pin GPIO18
  • Commanded range 0°–180°
  • Scan increment 15°
  • Type Positional, not continuous rotation

Power and Wiring

Power the ESP32 DevKit over USB or an appropriate regulated supply. Give the MG996R a separate suitable regulated 5 V high-current supply and connect its ground to ESP32 ground.

  • ESP32 USB / regulated supply
  • Servo External regulated 5 V supply
  • Grounds Common ESP32 / servo ground
  • GPIO pins Never power servo from GPIO

16×2 LCD and Scan Button

The I²C LCD shows scan progress, RSSI, best angle, and alignment status as supported by firmware. A push button controls scans in the current phone-hotspot firmware; it is an input, while the LCD is an output.

  • LCD address 0x27
  • I²C pins SDA GPIO21 / SCL GPIO22
  • Button wiring GPIO19 to GND
  • Button mode INPUT_PULLUP
