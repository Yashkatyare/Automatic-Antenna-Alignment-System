FAQ

Frequently Asked Questions

How does the system measure signal strength?

While connected to one Wi-Fi access point, the ESP32 DevKit reads RSSI in dBm through WiFi.RSSI(). The scan allows the reading to settle at each position before sampling.

What angular range does the antenna cover?

The MG996R positional servo scans the platform from 0° to 180° in 15° increments and returns to the angle associated with the strongest measured RSSI.

Can the dashboard connect to real hardware?

No. The website dashboard is an illustrative simulation and has no WebSocket, REST, or other live ESP32 telemetry connection.

How fast does the system find the strongest signal?

The scan uses 13 positions at 15° increments. Total duration depends on servo movement, signal settling, and the number of samples; no measured completion time is claimed.

Is this design specific to 2.4 GHz Wi-Fi?

This prototype measures Wi-Fi RSSI. The Teleten panel antenna's advertised 698–2700 MHz range includes 2.4 GHz Wi-Fi, but its Wi-Fi performance and advertised gain have not been independently verified, and external integration is under development.

ANTENNAALIGNMENT SYSTEM

An ESP32 DevKit-based Wi-Fi RSSI alignment prototype that scans a 0°–180° range and returns to its strongest measured direction.
