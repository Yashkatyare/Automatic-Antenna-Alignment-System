Project Overview

Why Antennas Should Point Themselves

A complete look at the problem this project solves, how it solves it, and why that matters for real-world wireless links.

Introduction

Precision Pointing for Directional Links

A directional antenna can focus reception when it is aimed correctly. This Wi-Fi prototype compares received signal strength across a single 0°–180° scan; the external panel antenna intended for the project has not been confirmed as connected to the working prototype.

The ESP32 DevKit connects to a Wi-Fi access point, reads its RSSI with WiFi.RSSI(), and commands a positional servo to scan the antenna platform. The controller selects the angle associated with the strongest measured RSSI.

At a Glance

  • Signal Source Phone hotspot (current test)
  • Controller ESP32 DevKit
  • Actuator MG996R positional servo
  • Scan Range / Step 0°–180° / 15°
  • Display 16×2 I²C LCD, address 0x27
  • Feedback Metric RSSI (dBm)

Problem Statement

Manually aligning directional antennas is slow, error-prone, and impractical for installations that need to adapt to moving transmitters, shifting environments, or unattended deployment. Static mounts fixed at installation time also cannot compensate for later obstructions, weather effects, or infrastructure changes — leading to degraded throughput and dropped links over time.

Objectives

• Design a mechanically rotating directional antenna platform.
• Connect the receiver to a selected Wi-Fi access point and read RSSI using WiFi.RSSI().
• Scan platform positions from 0° to 180° in 15° increments and select the strongest RSSI.
• Show local scan and alignment information on the I²C LCD.
• Present the website dashboard as a simulation; it is not connected to ESP32 telemetry.

Signal Quality

The scan selects the strongest RSSI observed at its sampled positions. No measured signal-strength improvement or throughput gain is claimed for this prototype.

Extended Range

Directional antenna alignment is the intended application. The external Teleten panel antenna is still under integration and its advertised specifications have not been independently verified.

Zero Manual Tuning

During a scan, the servo returns the platform to the angle associated with the strongest measured RSSI; continuous tracking is not claimed.

Working Principle

Sweep, Sample, and Settle on the Strongest Angle

1. Sweep

The MG996R positional servo moves the antenna platform from 0° to 180° in 15° steps.

2. Sample

After settling at each position, the ESP32 reads Wi-Fi RSSI with WiFi.RSSI().

3. Compare

The highest numerical RSSI (the least-negative dBm value) identifies the best sampled angle. Multiple-sample averaging depends on firmware support.

4. Lock

The servo returns to the best measured angle and the LCD reports that the best direction has been found.

Advantages

Push-button control starts the current scan workflow

Wi-Fi RSSI is read using the ESP32 Wi-Fi interface

Compares scan positions in a 0°–180° range

Local scan information is shown on the I²C LCD

Returns to the angle with the strongest sampled RSSI

External antenna integration remains under development

ANTENNAALIGNMENT SYSTEM

An ESP32 DevKit-based Wi-Fi RSSI alignment prototype that scans a 0°–180° range and returns to its strongest measured direction.
